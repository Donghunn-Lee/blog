이전 브라우저 렌더링의 이해 게시글에서 DOM을 먼저 설명한 바 있다. 하지만 DOM에 대한 자세한 설명은 없었다. 보다 최적화된 코드를 작성하기 위해 브라우저 렌더링 과정을 공부했다면, DOM은 브라우저가 웹 페이지를 구성하는 핵심 개념인 만큼 그 구조와 조작 방법의 이해를 통해 섬세한 DOM 컨트롤이 가능할하게 될 것이라고 생각한다.

## 1. DOM (Document Object Model)
DOM은 HTML문서의 구조를 트리 형태로 표현한 객체 모델이다. 우베 페이지의 모든 요소(태그)는 렌더링 과정에서 DOM 노드로 표현되며, JavaScript를 통해 DOM을 조작하여 웹 페이지의 내용, 구조, 스타일 등을 동적으로 변경할 수 있다.

### DOM 트리 구조

#### HTML 코드
```html
<!DOCTYPE html>
<html>
  <head>
    <title>DOM 예제</title>
  </head>
  <body>
    <div id="container">
      <h1>제목</h1>
      <p>내용</p>
    </div>
  </body>
</html>
```

#### DOM 트리
위와 같은 HTML문서는 다음과 같은 DOM 트리로 표현된다.
```
document
└── html
    ├── head
    │   └── title
    └── body
        └── div#container
            ├── h1
            └── p
```

---

## 2. DOM 노드 타입
돔을 구성하는 노드들은 기본적으로 객체이면서, 그 역할에 따라 몇 가지로 분류할 수 있다.

#### 1. 문서 노드 (Document Node)
- DOM 트리의 최상위 노드
- `document` 객체로 접근

#### 2. 요소 노드 (Element Node)
- HTML 태그를 표현
- `div`, `p`, `span` 등

#### 3. 텍스트 노드 (Text Node)
- 요소 노드의 텍스트 내용
- 공백 역시 텍스트 노드로 취급함

#### 4. 속성 노드 (Attribute Node)
- 요소의 속성을 표현
- `id`, `class`, `src` 등

---

## 3. DOM 조작
앞서 DOM 트리는 JavaScript로 조작이 가능하다고 했다. 보통 프론트 엔드 개발에서 JavaScript를 처음 접한다면 아마 이것일 것이다. `document.`를 사용해 각 메소드로 속성을 추가하거나 바꾸고 제거하는 등의 작업이다.


### 요소 선택
```js
// ID로 선택
const element = document.getElementById('myId');

// 클래스로 선택
const elements = document.getElementsByClassName('myClass');

// 태그로 선택
const divs = document.getElementsByTagName('div');

// CSS 선택자로 선택
const element = document.querySelector('.myClass');
const elements = document.querySelectorAll('p');
```

### 요소 생성 및 추가
```js
// 요소 생성
const div = document.createElement('div');

// 텍스트 노드 생성
const text = document.createTextNode('Hello');

// 요소 추가
parentElement.appendChild(childElement);
parentElement.insertBefore(newElement, referenceElement);

// 요소 제거
parentElement.removeChild(childElement);
```

### 속성 조작
```js
// 속성 설정
element.setAttribute('class', 'newClass');

// 속성 가져오기
const value = element.getAttribute('class');

// 속성 제거
element.removeAttribute('class');
```

이 밖에도 많은 메소드들을 사용해 요소를 선택하고 조작이 가능하다.

## 4. 이벤트 처리
DOM 요소를 설명하면서 이벤트 처리를 같이 얘기하는 이유는, JavaScript로 DOM을 조작하는 부분에서 각종 브라우저 이벤트 또한 다룰 수 있기 때문이다.
```js
element.addEventListener('click', function(event) {
    // 이벤트 객체의 주요 속성
    event.target        // 이벤트가 발생한 요소
    event.type         // 이벤트 타입
    event.preventDefault()  // 기본 동작 방지
    event.stopPropagation() // 이벤트 버블링 방지
});
```
이벤트 핸들러는 이벤트 객체를 위와 같은 형태의 배개변수로 받는다. 이런 식으로 요소에 이벤트 핸들러를 추가함으로써 이벤트를 처리할 수 있다.

다룰 수 있는 주요 이벤트 타입을 열거하자면 다음과 같다.

#### 마우스 이벤트
- click: 클릭
- dblclick: 더블 클릭
- mouseover: 마우스 진입
- mouseout: 마우스 이탈
- mousemove: 마우스 이동

#### 키보드 이벤트
- keydown: 키 누름
- keyup: 키 뗌
- keypress: 키 입력

#### 폼 이벤트
- submit: 폼 제출
- change: 값 변경
- focus: 포커스 획득
- blur: 포커스 상실

#### 문서 이벤트
- load: 로드 완료
- DOMContentLoaded: DOM 로드 완료
- resize: 창 크기 변경
- scroll: 스크롤

## 5. 이벤트 전파

### 이벤트 전파 단계

브라우저 이벤트의 독특한 점은, 이벤트가 이벤트 핸들러를 등록한 요소 뿐만 아니라, 다른 요소에도 전파된다는 점이다. 정확히는 DOM 트리를 기준으로 최상위 노드부터 이벤트 핸들러가 등록된 요소까지 이벤트가 전파되었다가, 다시 상위 노드로 올라간다. 각 과정의 설명은 다음과 같다.

#### 1. **캡처링 단계 (Capturing Phase)**
   - 이벤트가 최상위 요소(window)에서 타겟 요소로 내려가는 단계
   - `addEventListener`의 세 번째 매개변수를 `true`로 설정한 이벤트 리스너만 실행
   - 기본적으로는 실행되지 않음 (세 번째 매개변수의 기본값이 `false`이기 때문)

#### 2. **타겟 단계 (Target Phase)**
   - 이벤트가 실제 타겟 요소에 도달하는 단계
   - 캡처링과 버블링 모두의 이벤트 리스너가 실행

#### 3. **버블링 단계 (Bubbling Phase)**
   - 이벤트가 타겟 요소에서 다시 최상위 요소로 올라가는 단계
   - `addEventListener`의 세 번째 매개변수를 `false`로 설정하거나 생략한 이벤트 리스너만 실행
   - 기본적으로 이 단계에서 이벤트가 처리됨

#### 이벤트 전파 예시

```html
<div id="grandparent">
    <div id="parent">
        <div id="child">클릭하세요</div>
    </div>
</div>
```

```javascript
const grandparent = document.getElementById('grandparent');
const parent = document.getElementById('parent');
const child = document.getElementById('child');

// 기본값(false)으로 등록된 이벤트 리스너 (버블링 단계)
grandparent.addEventListener('click', () => console.log('버블링: grandparent'));
parent.addEventListener('click', () => console.log('버블링: parent'));
child.addEventListener('click', () => console.log('버블링: child'));

// true로 등록된 이벤트 리스너 (캡처링 단계)
grandparent.addEventListener('click', () => console.log('캡처링: grandparent'), true);
parent.addEventListener('click', () => console.log('캡처링: parent'), true);
child.addEventListener('click', () => console.log('캡처링: child'), true);
```

child 요소를 클릭하면 다음과 같은 순서로 출력된다.
```
캡처링: grandparent
캡처링: parent
캡처링: child
버블링: child
버블링: parent
버블링: grandparent
```

### 이벤트 전파 제어

기본적으로 이벤트는 전파되지만, 그러면 이벤트 버블링 단계에서 원하지 않는 상위 요소의 이벤트 핸들러까지 실행되어버릴수도 있다. 그래서 브라우저엔 **이벤트 전파를 제어 할 수 있는 방법**이 존재한다.

#### 이벤트 전파 중단
   - `event.stopPropagation()`: 이벤트의 전파를 중단
   - `event.stopImmediatePropagation()`: 같은 요소의 다른 이벤트 리스너도 중단

## 6. 이벤트 위임

이벤트 전파를 충분히 이해했다면, 이벤트 버블링으로 인해 원하지 않던 상위 요소의 이벤트 핸들러가 실행될 수도 있지만 이 현상을 의도적으로 활용할 수도 있겠다는 생각을 해 볼 수 있다. 이 방법을 **이벤트 위임** 이라고 한다. 이벤트 위임은 다시말해 여러 요소에 이벤트를 개별적으로 등록하는 대신, 공통 조상에 이벤트를 등록하여 처리하는 방식이다.

#### 이벤트 위임 예시
```js
const list = document.getElementById('list');

list.addEventListener('click', function(event) {
    if (event.target.matches('li')) {
        console.log('리스트 아이템 클릭:', event.target.textContent);
    }
});
```

---

## 7. 정리

**DOM**과 **이벤트 처리**는 웹 개발의 핵심 개념입니다. DOM을 통해 **웹 페이지의 구조를 조작**할 수 있고, 이벤트 처리를 통해 **사용자와의 상호작용**을 구현할 수 있습니다. 특히 **이벤트 위임**과 같은 패턴을 활용하면 효율적인 이벤트 처리가 가능합니다. 이러한 개념들을 이해하고 적절히 활용하면 더 나은 웹 애플리케이션을 개발할 수 있습니다.
