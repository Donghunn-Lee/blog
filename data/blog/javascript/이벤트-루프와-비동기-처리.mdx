> 개발을 하면서 다양한 이벤트를 다룰 때,  각각의 이벤트가 어떻게 처리되는지를 깊게 이해하려고 하지 않았다. 이벤트가 발생하면 발생 순서대로 처리된다. 이 정도만 알고 있었고, 비동기의 개념 또한 실행은 순서대로이지만 그 처리는 별도로 되는 것 정도로만 이해하고 있었다. 복잡한 이벤트를 처리할 상황에 대비해, 이벤트 루프와 비동기 처리에 대해 명확히 이해하고자 한다.

## 1. 왜 이벤트 루프를 알아야 할까?


```js
console.log('1');
setTimeout(() => console.log('2'), 0);
Promise.resolve().then(() => console.log('3'));
console.log('4');

// 출력 결과: 1, 4, 3, 2
```

위 코드를 보면 실행 순서가 직관적이지 않다는 것을 느낄 수 있다. 자바스크립트는 기본적으로 **단일 스레드**를 사용하는 **동기적 언어**인데, 왜 이런 비동기적인 처리가 가능할까?

이는 바로 웹 브라우저나 Node.js 같은 **호스트 환경에서 제공하는 이벤트 루프**가 비동기 처리를 대신 해주기 때문이다.

이벤트 루프를 이해한다면,

- 비동기 코드가 어떻게 실행되는지,
- `Promise`와 `setTimeout`의 실행 순서가 왜 다른지,
- 자바스크립트가 어떻게 단일 스레드로 동시성을 처리하는지

이러한 원리들을 명확히 알 수 있다. 이 지식을 바탕으로 더 효율적이고 예측 가능한 비동기 코드를 작성할 수 있고, 특히 복잡한 비동기 작업을 할 때 이벤트 루프의 동작 방식에 대한 이해도가 원하는 동작을 정확히 구현하는 데 큰 도움이 될 것이다.

---

## 2. 이벤트 루프란?

이벤트 루프는 자바스크립트의 **비동기 처리를 가능하게 하는 핵심 메커니즘**이다. 자바스크립트는 기본적으로 **단일 스레드(Single Thread)**로 동작하여 한 번에 하나의 작업만 처리할 수 있지만, 이벤트 루프 덕분에 비동기 작업을 효율적으로 관리하고 처리할 수 있는 것이다.

### 자바스크립트의 동시성 모델

자바스크립트는 다음과 같은 특징을 가진다:

- **단일 스레드로 동작**: 콜 스택이 하나여서 한 번에 하나의 작업만 수행한다.
- **이벤트 기반 비동기 처리**: 특정 이벤트(클릭, 네트워크 요청 등)가 발생하면 미리 정의된 콜백 함수를 실행한다.
- **논블로킹(Non-blocking) I/O 처리**: I/O 작업(파일 읽기, 네트워크 요청 등)이 완료될 때까지 메인 스레드를 멈추지 않고 다른 작업을 계속 수행할 수 있다.

이러한 특징들이 어떻게 조화롭게 동작하여 자바스크립트가 비동기 작업을 수행하는 것처럼 보이는지 이해하기 위해서는 이벤트 루프의 동작 방식을 정확히 알아야 한다.

---

## 3. 이벤트 루프의 구성 요소

이벤트 루프는 자바스크립트 엔진 외부(브라우저의 Web API 또는 Node.js의 C++ API)에 존재하며, 주로 다음 세 가지 주요 구성 요소를 통해 비동기 작업을 조율한다.

### 콜 스택 (Call Stack)

- 현재 **실행 중인 코드의 실행 컨텍스트를 저장하는 스택**이다.
- 함수 호출이 발생할 때마다 해당 함수의 실행 컨텍스트가 스택에 쌓인다.
- **LIFO(Last In First Out)** 방식으로 동작하며, 스택의 가장 위에 있는 함수가 실행 완료되면 스택에서 제거된다.

### 태스크 큐 (Task Queue)

- *매크로태스크(Macrotask)**를 저장하는 **큐(Queue)**이다.
- `setTimeout()`, `setInterval()`, DOM 이벤트(`click`, `load` 등), `requestAnimationFrame` 같은 비동기 콜백 함수들이 이 큐에 들어간다.
- **FIFO(First In First Out)** 방식으로 동작하며, 콜 스택이 비었을 때 이벤트 루프가 큐에서 하나의 태스크를 가져와 실행한다.

### 마이크로태스크 큐 (Microtask Queue)

- *마이크로태스크(Microtask)**를 저장하는 **큐**이다.
- `Promise`의 `then()/catch()/finally()` 콜백, `process.nextTick` (Node.js), `MutationObserver`, `queueMicrotask` 같은 비동기 콜백들이 이 큐에 들어간다.
- **태스크 큐보다 우선순위가 높다.** 이벤트 루프는 매크로태스크 큐를 확인하기 전에 마이크로태스크 큐가 완전히 비워질 때까지 모든 작업을 처리한다.

## 4. 이벤트 루프의 동작 과정

이벤트 루프의 동작 방식을 이해하는 것은 자바스크립트 비동기 코드의 실행 순서를 예측하는 데 매우 중요하다.

### 기본 동작 과정

이벤트 루프는 다음과 같은 순서로 끊임없이 동작하며 비동기 작업을 처리한다:

1. **콜 스택 확인**: 이벤트 루프는 항상 **콜 스택이 비어있는지** 확인한다. 콜 스택이 비어있지 않다면, 현재 실행 중인 동기 코드가 끝날 때까지 기다린다.

2. **마이크로태스크 큐 확인**: 콜 스택이 비어있다면, 이벤트 루프는 **마이크로태스크 큐**에 대기 중인 작업이 있는지 확인한다. 큐에 작업이 있다면, **모든 마이크로태스크**를 콜 스택으로 옮겨 실행한다. (새로운 마이크로태스크가 추가되면 그것도 실행)

3. **태스크 큐 확인**: 마이크로태스크 큐마저 비어있다면, 이벤트 루프는 이제 **태스크 큐**에 대기 중인 작업이 있는지 확인한다. 큐에 작업이 있다면, **단 하나의 태스크**만 콜 스택으로 옮겨 실행한다.

4. **렌더링**: (브라우저 환경의 경우) 필요한 경우 UI 렌더링이 발생할 수 있다. 이는 매크로태스크 하나와 다음 매크로태스크 사이에 일어나는 경우가 많다.

5. **반복**: 위 과정을 끊임없이 반복한다.

### 매크로태스크와 마이크로태스크

앞서 언급했듯이 이벤트 루프는 두 가지 종류의 비동기 작업을 다른 큐에 넣어 처리한다:

#### **매크로태스크**
`setTimeout`, `setInterval`, 사용자 인터랙션(`click`, `scroll` 등) 이벤트 핸들러, `requestAnimationFrame`, `UI 렌더링`, `script` (초기 전체 스크립트 실행) 등이 해당된다.

#### **마이크로태스크**
`Promise`의 `then/catch/finally` 콜백, `process.nextTick` (Node.js), `MutationObserver`, `queueMicrotask` 등이 해당된다.

이 둘의 가장 큰 차이는 **실행 우선순위**에 있다. 이벤트 루프는 매크로태스크를 실행하기 전에 **마이크로태스크 큐가 완전히 비워질 때까지 모든 마이크로태스크를 먼저 처리한다.**

```js
console.log('1');
setTimeout(() => console.log('2'), 0);
Promise.resolve().then(() => console.log('3'));
console.log('4');
```

이 코드의 실행 과정을 단계별로 자세히 살펴보자:

#### 1. **초기 동기 코드 실행**
  - `console.log('1')`이 콜 스택에 들어가 실행되고 `'1'`이 출력된다.
    
#### 2. **비동기 함수 호출**
   - `setTimeout(() => console.log('2'), 0)`이 호출된다. `setTimeout`은 Web API로 넘어가고, 0ms 타이머가 완료되면 콜백 함수가 **태스크 큐**에 들어간다.
   - `Promise.resolve().then(() => console.log('3'))`이 호출된다. `Promise`는 즉시 resolved 상태가 되고, `.then()` 콜백은 **마이크로태스크 큐**에 들어간다.
   - `console.log('4')`가 콜 스택에 들어가 실행되고 `'4'`가 출력된다.
    
#### 3. **콜 스택 비움**
   - 모든 동기 코드가 실행 완료되어 콜 스택이 비워진다.
    
#### 4. **마이크로태스크 큐 처리**
   - 콜 스택이 비어있으므로 이벤트 루프는 **마이크로태스크 큐**를 확인한다.
   - `Promise.resolve().then()` 콜백이 큐에서 나와 콜 스택에 들어가 실행되고 `'3'`이 출력된다. (마이크로태스크 큐에 다른 작업이 있다면 모두 처리할 때까지 이 과정 반복)
   
#### 5. **태스크 큐 처리**
   - 마이크로태스크 큐가 비어있으므로 이벤트 루프는 이제 **태스크 큐**를 확인한다.
   - `setTimeout` 콜백이 큐에서 나와 콜 스택에 들어가 실행되고 `'2'`가 출력된다. (태스크 큐는 한 번에 하나의 작업만 처리)

이 과정에서 **마이크로태스크 큐의 작업이 매크로태스크 큐의 작업보다 먼저 실행된다**는 것이 핵심이다. 이것이 바로 `Promise`의 콜백이 `setTimeout`의 콜백보다 먼저 출력되는 이유다.

## 5. 비동기 처리 방식

자바스크립트에서 비동기 작업을 처리하는 주요 방식들은 이벤트 루프를 통해 효율적으로 동작한다.

### 콜백 함수

```js
// 가장 기본적인 비동기 처리 방식 중 하나이다.
// 비동기 작업이 완료된 후 실행될 함수(콜백)를 인자로 받아 처리한다.
// 하지만 비동기 로직이 복잡해지면 콜백 함수들이 중첩되어
// '콜백 지옥(callback hell)' 문제가 발생할 수 있어 가독성과 유지보수가 어려워진다.
function fetchData(callback) {
    setTimeout(() => {
        callback('데이터');
    }, 1000);
}

// 사용 예시
fetchData((data) => {
    console.log(data); // 1초 후 '데이터' 출력
});
```

### Promise

```js
// ES6에서 도입된 비동기 처리 방식이다.
// 비동기 작업의 최종 완료 또는 실패를 나타내는 객체로,
// 'then()', 'catch()', 'finally()' 메서드를 체이닝하여 비동기 작업의 결과를 순차적으로 처리할 수 있다.
// 이를 통해 콜백 지옥 문제를 해결하고 더 깔끔하고 예측 가능한 코드 작성이 가능하다.
function fetchData() {
    return new Promise((resolve) => {
        setTimeout(() => {
            resolve('데이터');
        }, 1000);
    });
}

// 사용 예시
fetchData()
    .then(data => console.log(data)) // 1초 후 '데이터' 출력
    .catch(error => console.error(error));
```

### async/await

```js
// ES2017에서 도입된 비동기 처리 방식이다.
// Promise를 기반으로 동작하며, 비동기 코드를 마치 동기 코드처럼 직관적으로 작성할 수 있게 해준다.
// 'async' 키워드는 함수가 비동기 함수임을 나타내고, 항상 Promise를 반환한다.
// 'await' 키워드는 async 함수 내에서만 사용할 수 있으며, Promise가 resolve될 때까지 기다린다.
// 'try-catch' 문을 사용한 에러 처리도 동기 코드와 유사하게 구성할 수 있어 가독성이 매우 높다.
async function fetchData() {
    const data = await new Promise((resolve) => {
        setTimeout(() => {
            resolve('데이터');
        }, 1000);
    });
    return data;
}

// 사용 예시
async function main() {
    try {
        const data = await fetchData();
        console.log(data); // 1초 후 '데이터' 출력
    } catch (error) {
        console.error(error);
    }
}
main(); // async 함수 호출
```

## 6. 마무리

### 이벤트 루프 (Event Loop)

**이벤트 루프**는 자바스크립트의 **단일 스레드** 특성에도 불구하고 **비동기 작업을 효율적으로 처리**할 수 있게 하는 핵심 메커니즘입니다. 자바스크립트 엔진 외부의 호스트 환경(브라우저 Web API, Node.js API 등)에 존재하며, **콜 스택**, **태스크 큐(매크로태스크 큐)**, **마이크로태스크 큐**의 세 가지 주요 구성 요소를 통해 동작합니다.

이벤트 루프는 콜 스택이 비어있을 때 **마이크로태스크 큐의 모든 작업**을 먼저 처리한 후, **태스크 큐에서 하나의 작업**을 가져와 실행하는 과정을 끊임없이 반복합니다.

이벤트 루프에 대한 이해는 복잡한 비동기 코드의 **실행 순서를 예측**하고, **논블로킹(Non-blocking)** 방식으로 동작하는 자바스크립트의 동시성 모델을 깊이 이해할 수 있도록 돕습니다.
