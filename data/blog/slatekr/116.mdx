이번 세션은 이전에 확인했던 사항 중 F52 — closed fallback 경로로 anchor-echo 봉이 유입될 수 있다는 #113의 추정을 실측하고, 사실이면 필터를 넣는 작업이다. 그런데 세션을 열자마자 다른 게 먼저 걸렸다. 어제 저녁 run 목록을 훑는데 fetch_prices가 통째로 빨간불이었다.

---

## 비어있는 전일 캔들

로그는 시작부터 끝까지 전 종목 동일 에러 — KIS 서버 연결 타임아웃. 스크립트 문제가 아니라 저녁 16시 창에 KIS 접속 자체가 안 된 거라고 판단했다. 원인이 지속 중인지 봐야 해서 장중이었지만 바로 수동 재실행을 걸었다.

- 장중 실행 근거: end 캡(#098)이 조회 범위를 직전 거래일로 자름 — 첫 로그 `end 캡=2026-08-20` 확인
- 결과: 성공 2,644 · 오류 0 완주 → 어제 건은 KIS 일시 장애로 정리

근데 완주 직후 freshness verify가 FAIL을 냈다.

```
verify: FAIL — index_daily_prices.MAX(base_date)=2026-08-21 != expected 2026-08-20
  OK daily_prices.MAX(date) = 2026-08-20
```

잠깐 정상 범주로 읽을 뻔했다. 오늘 치가 없어서가 아니라, MAX가 기대보다 **미래**라는 뜻이다 — 낮 12시 장중 값이 이미 들어가 있다.

| | 종목 스크립트 | 지수 EOD 스크립트 |
|---|---|---|
| 설계 전제 | end 캡 내장 | 16시 마감 후 실행(#097) — 캡 없음 |
| 장중 수동 run 결과 | 차단 (OK) | 진행 중 값 4행 적재 (FAIL) |

수동 재실행이 workflow 전체 단위라 지수 스텝까지 같이 돈 게 발단이다. 적재가 write-once + incremental이라 방치하면 16시 정규 run이 08-21을 스킵하고 낮 12시 스냅샷이 확정 종가로 영구 고착된다 — 16시 전에 4행 삭제, 지수 스크립트 end 캡 이식은 F56으로 등록했다.

수확은 gate다. #107에서 "미래 날짜도 FAIL"로 짜둔 검증이 오적재를 당일에 잡았다. 이게 없었으면 지수 종가 네 개가 조용히 굳었을 거다.

## anchor-echo — 경로는 열려 있었고, 봉은 안 왔다

본작업. #113에서 관측한 anchor-echo 봉은 실체결 없는 anchor 시각을 요청하면 KIS가 마지막 상태를 복제해 돌려주는 인공 봉이다 — flat OHLC + 직전 거래량 복제. 거래량이 0이 아니라 빈 봉 가드를 통과한다. 당시 라이브 경로는 막았고, closed fallback만 유입 여지로 남겨뒀었다.

probe 1 — fallback 경로의 방어 상태 전수:

| 필터 | 라이브 | closed fallback |
|---|---|---|
| 마커·vol=0·sentinel | ✅ | ✅ |
| 세션 갭 anchor 컷 | ✅ | ❌ 미이식 |
| 미래 봉 시각 컷 | ✅ | ❌ 미이식 |
| 병합 계층 방어 | ✅ | 스킵 (조기 return) |

예상보다 열려 있었다. echo 봉이 오기만 하면 차트까지 직행이다.

probe 2 — "실제로 오는가". 웹과 동일 파라미터·anchor 세트로 직전 거래일 조회(저유동성 2종·NXT·대조군 삼성전자):

- echo 0건
- 마지막 실체결 이후 봉이 있긴 했는데, flat은 맞지만 거래량·거래대금이 **새로 증가** — 복제가 아니라 15:30 마감 단일가 체결봉. 단일가라 O=H=L=C가 필연이고 실제 매매라 거래량이 는다. 정상 데이터다
- 인공 봉 제외 파라미터 on/off diff도 완전 동일 — 억제할 대상 자체가 없음

정리되는 건 두 가지.

- **유입 없음** — #113의 echo는 라이브 엔드포인트가 진행 중인 미완 창을 forward-fill로 찍는 거동이고, 과거 확정일 조회는 만들 이유가 없는 봉이다. "fallback 유입 여지"는 검증 없이 남겨둔 추정이었고 실측이 반증했다
- **필터를 넣었으면 사고였다** — 추정 시그니처("flat + vol≠0")로 짰다면 마감 단일가 정상 봉을 오탐 제거했을 거다. 조회 서비스에서 오컷은 미적재보다 나쁘다

F52는 코드 변경 없이 종결한다. 재개 조건 하나만 남겼다 — 실기기 fallback 차트에서 마감 후 flat 봉 재관측 시 그 날짜·종목으로 재측정.

## 해외 차트 거래량 축 정리

여력이 남아 F51. 미국 지수 intraday 차트에 거래량 축은 그려지는데 값이 없는 증상이다.

원인은 반쯤 알고 있던 거였다 — 해외 지수 분봉의 거래량은 항상 0이라는 실측 주석이 collector·웹 양쪽에 있고, 전 계층이 그 판정대로 거래량을 의도적으로 무시한다. 유일한 부정합이 렌더 층이다. showVolume이 무조건 켜져 있어 값이 없어도 하단 여백을 예약한다. 해외 intraday 뷰에서만 끄는 걸로 정리했다.

실기기 확인 중 일봉이 눈에 들어왔다. S&P500·나스닥100 두 지수만 일봉에서도 거래량이 0이다. 지수별로 갈린다는 얘기라 DB 전수를 떴다.

| 지수 | 실값 행 | 판정 |
|---|---|---|
| 나스닥100 | 10,313행 중 0 | 전 기간 미제공 |
| S&P500 | 2015-01-30까지만 | 이후 11년 미제공 |
| 나머지 6종 + 국내 | 최신까지 실값 | 정상 |

수집 버그가 아니라 원천이 지수별로 안 주는 거다. 백필 때부터 이 상태였는데, intraday 여백을 걷어내니 대비가 생겨 그제야 보였다.

처리는 #115 지연 registry와 같은 패턴 — 실측 확정 사실만 지수별 상수에 등재, 등재 지수는 일봉 축도 숨김. 트레이드오프로 S&P500 전체 뷰의 1985~2015 실값 구간까지 같이 사라지지만, 기본 뷰(최근 구간)에서 11년째 빈 축만 보이는 상태라 숨기는 쪽을 택했다.

## 다우 셀이 0이 됐다

실기기 확인 중 이번엔 홈이 이상했다. 다우 셀이 `0 · 0.00%`. 차트엔 어제 캔들이 멀쩡히 있는데.

원인 분리:

- 방금 커밋 영향 — 배제. diff는 상수 추가뿐, quote 경로 접점 없음
- route 응답 실측 — KIS가 다우 현재가 응답 전 필드를 0으로 반환 중. 같은 응답에서 나머지 7종 정상
- 미국 날짜 롤오버 리셋 가설 — 기각. 같은 미국 지수 S&P·나스닥이 정상이면 공통 현상이 아니고, #115의 네 시장 마감 동결 실측과도 어긋남

다우 quote는 원래 KIS가 전일 EOD를 에코해 채우는 합성값(#114)이라, 그 합성 경로 어딘가가 빈 것으로 보인다. 일회성인지 반복 창인지는 관측 한 번으로 단정할 수 없어 재관측으로 넘겼다.

대응에서 잠깐 샛길로 갈 뻔했다. 마지막 유효 값을 저장해 둬야 하나 — 근데 다우 quote의 내용물이 애초에 전일 EOD니 보존해 봤자 DB에 있는 값의 사본이다. 문제는 값이 사라진 게 아니라, **무효한 0이 유효한 quote 행세를 하며 서열 최상위를 점거해 아래의 정상 폴백(EOD)을 가리는 것**이었다.

수정은 가드 하나다.

- fetch 계층에서 가격 0 이하 quote를 null로 강등 — 지수 값 0은 어떤 지수에도 정상일 수 없어 오탐 없는 조건
- null이 되면 기존 quote → 분봉 → EOD 서열이 알아서 전일 종가로 하강
- 다우 전용 분기 없음 — #115에서 특례를 걷어낸 방향 그대로, 타 지수 동일 회귀도 커버

마침 KIS가 0을 주고 있는 창이라, 배포하자마자 셀이 전일 종가 + 기준일 라벨로 전환되는 것까지 바로 확인됐다.

## 정리

- **F52 종결** — probe 2회, 코드 변경 없이. 경로는 열려 있었지만 유입이 없고, 추정대로 필터를 넣었으면 정상 봉을 오탐했을 것
- **F51 종결** — 해외 intraday 거래량 축 전면 off + 일봉은 DB 전수 실측 기반 지수별 registry
- **무효 quote 가드** — 다우 현재가 0 회귀를 price ≤ 0 → null 강등으로 처리, 기존 폴백 서열이 자연 흡수
- **장애 대응** — 어제 EOD 누락 수동 회복 + 그 과정의 지수 장중 오적재를 gate가 포착, F56 등록

만든 코드는 게이트 한 줄과 가드 함수 하나가 전부인데, 세션 내내 잰 게 그보다 많았다. 필터는 실측이 필요 없다고 답했고, 거래량 축은 실측이 지수별로 갈라줬고, 장애 복구는 자기가 만든 오적재를 자기 gate로 잡았다. 안 만든 것에도 근거가 남는 세션이었다.
