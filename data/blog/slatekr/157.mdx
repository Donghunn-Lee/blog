9월 14일부터 한국거래소가 16시부터 20시까지 애프터마켓을 열고 시간외단일가를 없앴다. SlateKR은 "15시 30분 이후 움직이는 종목은 NXT 대상 종목뿐"이라는 등식 위에 시세 게이트·출처 배지·마감 스냅샷·EOD 가드를 세워 왔고, #154에서 이 등식이 깨지는 날에 맞춰 대응 항목(X27)을 세우고 저녁 실측 다섯 문항을 정해 뒀었다.

계획은 주말에 README 초안을 마무리하고 월요일 저녁에 실측만 하는 것이었는데, README는 추후 변경사항 반영해서 별도로 이어 쓰기로 하고 월요일은 X27에 전부 썼다. 정적 조사와 실측을 오전과 저녁으로 나눴고, 실측이 예상보다 단순하게 나와 조치 네 커밋까지 당일에 넣었다. 다만 일봉 문항이 예상 밖으로 나와 EOD 적재는 하루 미뤘다.

---

## 정적 조사로 뒤집힌 전제 셋

실측은 16시 전엔 할 수 없으니 오전에는 코드 쪽을 먼저 봤다. 세션 판정 함수의 마감 후 분기 소비처, NXT 대상 여부로 라이브를 가르는 지점, 배지와 캡션 문구, collector의 가드 시각, 120봉 전환(X28)에서 세션으로부터 파생시킨 분 슬롯이 경계 변경을 따라오는지까지 좌표를 뜨는 작업이었다. 그런데 좌표보다 먼저 나온 건 계획 단계의 전제 세 개가 틀렸다는 사실이었다.

| 전제 | 실제 | 영향 |
|---|---|---|
| 세션 판정 함수에 16:00·20:00 경계를 새로 넣어야 함 | 마감 후 15:30~20:00이 이미 하나의 세션. 없는 건 16:00뿐 | 세션 상태 신설 불요 |
| EOD 적재는 write-once라 재실행 불가 | upsert지만 종목별 마지막 적재일 다음 날부터 받는 규칙이라 재실행이 no-op | 첫 run 전에 cron을 멈춰야 하는 건 같음 |
| 20:10 스냅샷이 NXT 대상 종목만 담음 | 활성 전 종목, 통합·NXT 두 채널 | 비NXT 장외가가 오늘부터 그대로 잡힘 |

첫 번째가 설계 방향을 정했다. 마감 후 세션의 소비처가 스무 곳 가까이 되는데 16시가 필요한 곳은 라벨·캡션·슬롯 셋뿐이라, 세션을 쪼개는 대신 16시 판정 함수 하나를 두는 쪽이 범위가 훨씬 작았다.

## 저녁 실측 다섯 문항

종목 넷을 골라 KIS 응답 전체를 15:47·16:31·마감 후 세 시점에 덤프하고 필드 단위로 diff했다. NXT 대상 대형주 하나, 비NXT 활발주 둘, 초저유동 스팩 하나다. 현재가 한 필드만 보면 우연에 속을 수 있어 통째로 받았는데, 실제로 그 우연이 하나 있었다.

| 문항 | 판정 | 근거 |
|---|---|---|
| 비NXT 현재가가 16시 이후 움직이는가 | **전 종목 움직임** | 주성엔지니어링 206,000→203,500원, 대우건설 18,760→18,560원. 초저유동 스팩도 1주 체결로 +4% |
| KRX 채널 분봉이 20시까지 나오는가 | 실봉 반환 | 16:27~16:31 봉 거래량 162~574주 |
| 일봉이 16시 이후 갱신되는가 | **갱신됨** | 아래 절 |
| 통합 채널이 KRX+NXT 합산인가 | **합산** | 삼성전자 누적 거래량 23,968,506주 = KRX 16,682,895 + NXT 7,285,610 (오차 1주). 분봉도 합산 |
| 지수가 애프터마켓 중 산출되는가 | 미산출 | 지수값 불변 |

삼성전자의 KRX 채널 현재가만 안 움직여 잠깐 "NXT 종목은 KRX 애프터에서 빠지나" 싶었는데, 분봉을 보니 분당 천 주 단위로 체결되고 있었고 애프터 체결가가 정규장 종가 249,000원과 같았을 뿐이었다. 통합 채널이 합산이라는 것이 확인되면서 비NXT 종목을 KRX 채널로 따로 보낼 이유가 없어졌다.

## 결정 넷

| 후보 | 판정 |
|---|---|
| 마감 후 세션을 15:30~16:00 / 16:00~20:00으로 분리 | 기각. 소비처 전수 수정 |
| **16시 판정 함수 하나, 라벨·캡션·슬롯만 소비** | **채택.** 세션 판정 함수 무변경 |
| 마감 후 미지정 시세를 비NXT는 KRX, NXT 종목은 NXT 채널로 분기 | 기각. 종목 속성 조회가 route에 남음 |
| **마감 후 미지정 시세를 전 종목 통합 채널로** | **채택.** 합산이 실증됐고 관심목록 다건 시세는 이미 통합이라 변경 0 |
| "NXT" 배지 유지 | 기각. 합산값이면 NXT 종목에서도 부정확, 비NXT는 16시 이후 오표기 |
| **출처 축을 세션 축으로, "장외" 배지** | **채택.** 판정 조건(정규장 종가와 다름)은 그대로 |
| 헤드라인에 공식 종가, 장외 현재가는 보조 | 기각. NXT 탭 선례와 어긋남 |
| **헤드라인은 장외 현재가 + 라벨, 공식 종가는 EOD 패널** | **채택.** #124 NXT 탭과 같은 규칙 |

```
전                                            후
15:30~20:00 미지정 시세 → NXT 채널             15:30~20:00 미지정 시세 → 통합 채널
  비NXT → null → 전일 EOD 표시                   비NXT 16:00~ → KRX 애프터 현재가
스냅샷 서빙: 비NXT는 null                       스냅샷 서빙: 전 종목 장외 마지막 체결
배지 "NXT" (출처)                               배지 "장외" (세션)
KRX 탭 라벨: 마감 후 "장 마감 · 15:30"             16:00~ "애프터마켓 · HH:MM", 20:00~ "애프터마켓 종가 · 20:00"
분봉 anchor: KRX 4(~15:30) / NXT 6(~20:00)       단일 세트 6, 비NXT 슬롯 16:00~20:00 편입
```

구현하면서 하나 더 잡았다. 토글이 없는 비NXT 종목은 헤더 라벨이 NXT 분기를 타서 15:30~16:00에 "애프터마켓 · 15:47"이 값은 종가 그대로인 채 뜨길래 이 경로에도 16시 게이트를 걸었고, 값은 null로 지우지 않았다. EOD가 아직 없는 그 창에서 라이브를 지우면 전일 값으로 돌아가기 때문이다.

차트의 확장 세션 표시도 15:47 시간외 종가매매 실봉 하나가 16시 전에 "KRX 애프터마켓"을 켜고 있어 비NXT는 16시 이후 봉이 있을 때만 켜도록 바꿨다. 커밋은 라벨 → 채널 → 배지 → 차트 순으로 넣었는데, 채널을 먼저 열면 "장 마감 · 15:30" 옆에 애프터 가격이 서는 중간 상태가 생겨서다.

(스크린샷: 주성엔지니어링 헤더 "애프터마켓 종가 · 20:00"과 관심목록의 장외 배지)

## 일봉 오염과 미룬 EOD

### 마감 후에도 남은 애프터 체결가

세 번째 문항은 "일봉의 시가·고가·저가·거래량이 16시 이후 갱신되는가"였고, 답이 단순히 "예"가 아니라 종가까지 애프터 체결로 덮여 있었다. 공식 종가는 15시 30분 값으로 고정된다는 것이 제도인데, KIS 일봉은 마감 후에도 그날 마지막 체결을 종가로 돌려줬다.

| 종목 | 정규장 마감값 | 마감 후 KIS 일봉 | 차이 |
|---|---|---|---|
| 주성엔지니어링 종가 | 206,000원 | 202,500원 | -3,500원 |
| 주성엔지니어링 거래량 | 751,952주 (15:47) | 892,311주 | +140,359주 (16%) |
| 삼성전자 저가 | 248,500원 | 247,000원 | -1,500원 |
| 스팩 고가 | 1,997원 | 2,075원 | +78원 |

### 미룬 이유와 갈림길

이날 EOD는 20시 10분 이후 수동으로 돌리기로 했었는데, 이 값을 그대로 적재하면 되돌리기 어렵다. 재실행이 no-op인 구조라 한 번 들어간 종가는 백필 경로로만 고칠 수 있다. 그래서 수동 실행도 하지 않고 화요일 아침으로 미뤘고, 밤사이 KIS 배치가 일봉을 공식 종가로 정정하는지와 다음 날 기준가가 어느 값인지에 따라 캡처 시각이 갈린다.

| 아침 확인 결과 | EOD 방향 |
|---|---|
| 일봉 정정, 기준가 = 공식 종가 | 15:32 캡처 + 아침 재조회 |
| 일봉 미정정, 기준가 = 공식 종가 | 15:32 캡처 단독. 시간외·애프터 거래량 미포함 고지 |
| 둘 다 마지막 체결 | 15:32 캡처 + 20:20 재조회, 또는 종가 정의 재검토 |

어느 쪽이든 "마지막 저장일을 다시 받는" 능력이 공통이라 적재 규칙을 그쪽으로 손볼 계획이고, 아침에만 적재하는 안은 매일 저녁 네 시간을 전일 값으로 보내게 돼 처음부터 뺐다. 이번 채널 전환으로 EOD에 기대는 표면이 오히려 늘었기 때문이다.

## 정리

- **X27 구현(커밋 1~4)** — 세션 판정 함수 무변경, 16시 판정 함수 하나. 마감 후 미지정 시세 통합 채널, 스냅샷 비NXT 게이트 제거, 배지 "NXT"→"장외", KRX 탭 라벨 16:00·20:00 축, 분봉 anchor 단일 세트와 비NXT 슬롯 16:00~20:00
- **X27 이월** — KIS 일봉이 마감 후에도 애프터 마지막 체결. EOD 수동 실행 보류, 아침 정정 여부와 기준가로 캡처 시각 확정
- **통합 채널 합산 실증** — 누적 거래량 KRX+NXT 오차 1주. 비NXT 분기 불요의 근거
- **뒤집힌 전제 셋** — 세션 경계 기존재, write-once 아닌 skip, 스냅샷 전 종목. 설계 범위가 여기서 줄어듦

정적 조사가 계획의 전제를 셋이나 뒤집었는데, 그 덕에 저녁 실측 뒤 남은 게 채널과 라벨뿐이었다. 사실 UI 쪽이 예상보다 쉬웠던 만큼 일봉 쪽은 좀 뜻밖이었고, 제도 문서의 "공식 종가 유지"와 데이터 벤더의 일봉이 같은 말이 아니라는 걸 첫날에 본 건 다행인 편이다.
