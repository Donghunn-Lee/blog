어제가 광복절 대체공휴일이라 F28 실측이 하루 밀렸다. 오늘 07:53부터 프리마켓 진입(08:00), NXT 프리마감(08:50), 개장(09:00)까지 창을 따라가며 확인했다. #092에서 코드로만 닫고 장중 실측으로 미뤄둔 항목들이 대상이다.

확인하려던 것들은 대부분 예상대로 돌았다.

- NXT 종목 당일 분봉 08시 유입·라이브 갱신 (#092)
- 08:50~09:00 늦은 preopen NXT 봉 유지 (#102)
- 해외 quote 폴링의 KST 05~09 인터벌 정지와 09:00 재개
- countup 폴링 갱신 애니·탭 전환 무애니 (#111)

대신 계획에 없던 문제가 세 개 나왔다.

## 일봉 캔들과 아침 리셋

**1. 프리마켓 중에 "KRX" 라벨 일봉에 당일 캔들이 생겼다.** 값은 NXT 프리장 OHLC다. #092의 도지 게이트는 무효 quote(시·고·저 0)만 보는데, NXT 종목은 프리장에도 정상 OHLC가 와서 그대로 통과한 것. 정규장 캔들 자리에 NXT 값이 앉는 건 라벨과 소스의 모순이라, 개장 전엔 당일 캔들을 아예 만들지 않는 걸로 정리했다 — 프리장 가격은 헤더가 이미 보여주니 정보 손실도 없다. 병합 함수는 두고 호출하는 세 컴포넌트에서 개장 전이면 quote를 null로 넘긴다.

![스크린샷: 프리마켓 중 일봉에 생긴 당일 캔들](/static/images/velog/a6cc450d-edb6-4685-8d74-db94f6d92709-image.png)


**2. KRX 전용 종목만 아침 리셋에서 빠져 있었다.** 08:00~08:50 구간에 NXT 종목은 "프리마켓 + 당일 값"인데, NXT 미거래 종목은 "장 마감 + 금요일 등락"이 그대로였다. 06:00 리셋(전 종목 0% + 전일 종가)은 정상 동작 중이었고, 08:00에 pre 세션으로 넘어가면서 폐장 보존용 분기(isNxtMiss)가 이 구간까지 덮은 게 원인 — #064에서 preopen과 closed를 가를 땐 pre라는 세션이 없었고, #092에서 생기면서 사각이 됐다.

| 구간 | NXT 종목 | KRX 전용 종목 |
| --- | --- | --- |
| 06:00~08:00 | 장 시작 전 · 0% | 장 시작 전 · 0% |
| 08:00~08:50 | 프리마켓 · 당일 값 | ~~장 마감 · 전일 등락~~ → **장 시작 전 · 0%** |
| 08:50~09:00 | 장 시작 전 · 0% | 장 시작 전 · 0% |

바뀌는 칸은 하나다. 장 마감 후의 등락 보존(#064)은 그대로 두고, 헤더 분기를 술어 둘로 정리했다.

프리장 헤더(NXT 값)와 차트(KRX 기준)의 출처 혼선은 남았는데, 표시 체계 설계가 붙는 문제라 E50으로 따로 등록했다.

## 동시호가 구간에 쌓이는 거래량 0 봉

08:50이 지나자 분봉 차트에 작대기가 분마다 붙기 시작했다. 시=고=저=종이 마지막 체결가로 같은 거래량 0 봉인데, 이 구간은 NXT 프리마켓이 끝나고 KRX는 호가만 받는, 체결이 있을 수 없는 시간이다. 개장하면 지워지려나 싶어 09:00을 넘겨 봤는데 그대로 남았다.

![스크린샷: 개장 후에도 남은 08:50~09:00 플랫 봉](/static/images/velog/09693c29-eafb-48c1-bb23-6cf958c01e6a-image.png)


우리 병합 로직은 마지막 봉의 종가만 바꾸고 새 봉을 붙이지 않으니, 남는 용의자는 KIS 응답이었다. raw를 떠 보니 원본이 맞았다 — KIS 통합(UN) 분봉은 세션 갭을 비워두지 않고 직전 체결가로 채워 보낸다. 08:50~08:59 열 개 봉 전부 거래량 0에 누적 거래대금이 십 분간 한 자리도 안 움직였다. 기존 sentinel 필터(시·고·저 0, 음수 거래량)는 실제 가격이 든 이 봉을 거를 수 없다.

필터 조건을 정하는 데서 방식이 갈렸다.

| 방식 | 장점 | 걸리는 점 |
| --- | --- | --- |
| 시간 구간 컷 | 단순하고 의도가 구간 정의에 드러난다 | 창 경계를 정확히 알아야 한다 |
| fill 패턴 판정 (플랫 + vol 0) | 구간 하드코딩이 없다 | 저유동성 종목의 정당한 봉을 지울 여지 |

구간 컷으로 가되 조건 하나를 얹었다. 컷 대상은 체결이 제도적으로 불가능한 구간만 — 오전 갭(08:50~08:59)과 마감 동시호가 접수(15:20~15:29) — 담고, 창 안이어도 거래량 0일 때만 지운다. 구간 정의가 틀렸거나 KIS 발행 규칙이 바뀌어도 실체결 봉은 살아남는다.

```ts
const DOMESTIC_SESSION_GAP_WINDOWS: readonly (readonly [string, string])[] = [
  ["0850", "0859"], // NXT 프리마감 ~ KRX 개장
  ["1520", "1529"], // KRX 마감 동시호가 접수 — 15:30 실체결 봉은 창 밖
];

export const isDomesticSessionGapFill = (hhmmss: string, volume: number): boolean =>
  volume === 0 && isWithinGapWindow(hhmmss.slice(0, 4));
```

구간 경계는 KIS 라벨이 그 분의 시작(09:00 라벨 = 09:00:00~59 체결)이라는 걸 HTS와 대조해 확정하고 그었다. 개장 봉(09:00)과 마감 단일가 봉(15:30)은 구간 밖에 남는다.

거래량 0 가드는 당일에 바로 값을 했다. 마감 전 raw에선 15:19도 fill이었는데 정규 매매 시간대라 구간에 안 넣었고, 장이 닫힌 뒤 다시 떠 보니 그 자리에 실봉(거래량 13,931)이 소급으로 들어와 있었다. 규정 근거가 확실한 범위만 구간에 담는 원칙이 몇 시간 만에 실측으로 확인된 셈이다.

적용 후 NXT 종목은 오전·마감 구간 20봉이 사라지고 08:49·09:00·15:30 실봉이 남았다. 마감 구간은 오전과 달리 KRX 단독(J) 응답에도 fill이 와서, KRX 전용 종목까지 같은 필터가 닿는 것도 확인했다.

## 정리

- **일봉 개장 전 병합 차단** — NXT 프리장 값이 KRX 일봉 당일 캔들로 붙던 것을 소비처 게이트로 차단
- **아침 리셋 통일** — KRX 전용 종목이 프리마켓 시간대에 전일 등락으로 되돌아가던 구멍을 메워 개장 전 전 구간을 "장 시작 전 · 0%"로
- **세션 갭 fill 봉 컷** — 거래량 0 봉이 KIS 원본의 fill-forward임을 확정하고, 체결 불가 창 + 거래량 0 이중 조건으로 필터
- **실측 종결** — 분봉 확장·preopen 봉 유지·해외 폴링 게이트·countup 전부 설계대로 확인

셋 다 코드만 봐서는 못 잡는, 실제 장 시간이 흘러야 드러나는 부류였다. 오늘 고친 것들이 프리마켓에서 제대로 도는지는 내일 아침 같은 창에서 다시 본다.
