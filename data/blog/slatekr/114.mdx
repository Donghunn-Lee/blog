지난 세션에서 지수 페이지 헤더를 해외 현재가 라이브로 바꿨더니, 그 아래 일봉 차트만 어제(아시아는 그저께) 캔들에 멈춰 있는 갭이 생겼다. 국내 차트에 있는 당일봉 병합을 해외로 넓히는 게 이번 작업, E51이다.

오후 착수라 시간대가 좋았다 — 항셍·상해가 장중, 16:00엔 EOD 적재, 밤엔 미국 개장. 병합이 열리고 닫히는 전 과정을 하루 안에서 볼 수 있었다.

본작업 전에 어제 미뤄둔 검증 하나를 종결했다. 마감 직후 체결 없는 구간(15:31~15:39)을 분봉에서 잘라내는 필터가 실제 응답에서도 설계한 경계대로 도는 걸 확인했다 — 아홉 봉이 잘리고 15:30·15:40 실봉은 남았다.

---

## quote 직결로 병합 로직 교체

조사해 보니 지수 차트엔 해외 당일봉 병합이 이미 있었다. #094에서 미국 분봉을 웹에 연결할 때 들어간 것으로, 당일 분봉을 시·고·저로 집계해 국내와 같은 병합 함수에 넘기는 방식이다. 문제는 이 경로가 분봉이 있는 미국 3종만 커버하고, 분봉 자체가 DB 확정봉이라 10~15분 늦다는 점이다. #113에서 헤더를 quote로 통일해 놓으니 이번엔 헤더와 마지막 봉이 갈린다.

| 방식 | 내용 | 걸리는 점 |
| --- | --- | --- |
| 분봉 합성 유지 | 당일 분봉을 시·고·저로 집계해 병합 | 미국 3종 한정, 지연 봉이라 헤더 quote와 값이 갈린다 |
| quote 직결 | 헤더와 같은 quote를 당일봉으로 | 분봉 없는 5종까지 8종 공통, 국내와 같은 패턴 |

quote 직결로 교체했다. 지난 세션에 홈과 지수 페이지의 값 이원화를 정리해 놓고 여기서 헤더-차트 이원화를 남기면 같은 문제의 재생산이다. 합성 로직은 걷어냈고, 분봉은 차트 전용으로 남는다.

병합 여부는 체결 일자 하나로 가른다. #113에서 라벨용으로 파싱해 둔 체결시각이 그대로 게이트 재료가 됐다.

```ts
// 병합 게이트 — 체결 일자가 마지막 일봉보다 새로울 때만
if (!quote?.time) return null;                 // 다우: 체결시각 없음 → 자연 차단
const d = quote.time.date;                     // "20260819"
const iso = `${d.slice(0, 4)}-${d.slice(4, 6)}-${d.slice(6, 8)}`;
return iso > latestDailyDate ? iso : null;     // 폐장 quote도 EOD 전진 전까진 통과
```

폐장 후에도 게이트가 열려 있는 동안은 quote 봉을 유지하기로 했다. 폐장 quote엔 마지막 세션 값이 담겨 있으니 EOD가 들어오기 전까지 그 봉이 최신 세션을 대신하고, EOD가 들어오면 날짜가 같아져 게이트가 저절로 닫히면서 확정봉으로 갈아 끼워진다. 여기도 세션 판정은 필요 없었다.

실측은 시간대를 따라갔다. 항셍이 장중에 병합되고, 상해가 마감 후에도 당일 봉을 유지하고, 16:00 적재가 돌자 나스닥종합의 quote 봉이 확정봉과 소수점까지 수렴하며 교체됐다. 국내 차트도 같은 경로를 지나므로 무회귀까지 확인했다.

## 당일 봉 옆의 전일 구멍

그런데 항셍 차트에 8/19 봉이 붙자, 그 옆의 8/18이 비어 있는 게 눈에 들어왔다. 아시아 EOD는 16:00 run이 적재하는데, 적재 스크립트는 진행 중 봉을 거르려고 당일 날짜 봉을 거부한다(#109). 아시아 마감 봉은 run 시점에 "당일 날짜"라 걸러지고, 다음날 16:00에야 들어온다 — 약 25시간 지연이다.

E51 전에는 "차트가 이틀 늦다"로 뭉쳐 보이던 게, 당일이 채워지자 "전일이 빠진 채 당일이 붙는" 모양으로 바뀌었다. legend 등락률도 이틀 전 종가 대비로 계산돼 헤더와 어긋난다. 매일 오전마다 반복될 상태라, 로드맵에 등록만 해뒀던 새벽 run 분리(F53)를 이 세션에서 당겼다.

밤에 KIS 일봉 API를 8종에 대해 실측했다. 마감 6~8시간이 지난 시점에 아시아 3종의 당일 EOD가 이미 회신되고 있었다. 항셍 값이 처음엔 33pt 편차로 보였는데, 엄밀히는 대조값 쪽이 마감 전 캡처였던 거고 폐장 후 화면값과는 소수점까지 일치했다. 유럽·미국은 장중 진행 봉을 거래량 0으로 노출하고 있어서, 당일 날짜 거부 필터가 새벽 run에도 그대로 필요하다는 것까지 같이 확인됐다.

run 시각은 07:30 KST로 정했다.

- 아시아 마감 +15~17h — 이번 실측이 6~8h 회신을 확인했으니 여유가 크다

- DAX 마감 +6~7h — 아시아 관측과 대칭이라 안전권으로 봤다
- 미국 마감 +1.5~2.5h — 경계다. 확정봉이 안 나오면 시각만 뒤로 미루면 된다

구현할 게 없었다. workflow엔 해외만 도는 mode 입력과 게이트 skip이 #107 장애 대응 때 이미 들어가 있어서, cron-job.org에 07:30 트리거 하나를 등록한 게 전부다. 기존 16:00 run의 해외 파트는 백스톱으로 남겼다 — upsert가 멱등이라 겹쳐 돌아도 무해하고, 새벽 run이 실패하면 오후가 받아준다. 요일은 화~토로 걸었다. 월요일 새벽엔 주울 봉이 없다.

## 다우 quote는 EOD만 제공

F53 실측에서 다우만 daily 응답에 당일 진행 봉이 없는 게 보였다. 분봉 미제공(#107)이야 확정해 둔 사실이지만, quote 값이 장중에 움직이는지는 확인한 적이 없다는 걸 그제야 알았다 — #113의 "값은 유효" 판정은 폐장 시간대 확인이었다.

미국 장중에 3분 간격으로 세 번 호출해 봤다. S&P는 분마다 움직이는데 다우는 세 번 모두 전일 종가와 소수점까지 같았고, 전일 대비마저 하루 전 기준으로 얼어 있었다. 지연 시세가 아니라 전일 EOD의 에코다. 다우존스 지수는 라이선스 비용 때문에 벤더들이 실시간 재배포에서 빼곤 하는 종목이라, KIS 무료 시세에서 다우로 얻을 수 있는 건 전일 확정 일봉 하나로 정리된다.

E51 게이트는 체결시각이 없는 다우를 어차피 차단하니 이 에코 값이 차트에 섞일 일은 없다. 남는 건 라벨이다. 화면엔 "~15분 지연" 배지가 붙어 있는데 실제는 하루 전 값이니 사실과 다른 표기다. 값 자체는 정확하고 기준일이 병기돼 있어 급하진 않지만, 기준시각 라벨 체계를 정비하는 E52에서 "전일 종가" 계열로 바꾸기로 하고 이번엔 기록만 남겼다.

## 정리

- **E51 종결** — 해외 일봉 당일 병합을 분봉 합성에서 quote 직결로 교체, 대상 3종 → 8종. 장중 병합·폐장 유지·EOD 교체까지 하루 안에서 전부 관측
- **F53 1단** — 아시아 EOD 25시간 지연의 해소로 07:30 새벽 run 등록. 코드 변경 없이 크론 하나
- **다우 quote 에코 확정** — #113 판정 정정, 라벨 정직화는 E52로 이관
- **이월분 종결** — gap-cut 창 실응답 검증, 해외 EOD 전진 확인

코드보다 그 뒤에 딸려 나온 관측이 많은 세션이었다. 당일 봉을 채우니 전일 구멍이 보였고, 구멍을 조사하다 다우의 실체가 나왔다. 표시를 하나 고칠 때마다 그 뒤에 가려져 있던 다음 문제가 드러나는 순서가 이어지고 있다.
