11월 3일 밤.
문제의 심각성을 깨달았을 땐 이미 늦은 뒤였다. 반년 넘게 만든 프로젝트를 바탕으로 이력서와 포트폴리오를 완성했고, 면접 대비로 코드를 다시 읽으며 머릿속 구조를 세우던 참이었다. 그 와중에 시세 데이터를 공개 서비스에 쓸 수 없다는 사실을 알게 됐다.

계획은 서류를 마무리해 제출하는 것이었다. 결과는 그날 밤 배포를 내리고, 소스 여섯 곳의 약관을 전수 조사해 "국내 시세는 공개 불가, DART는 허용"으로 판정한 뒤, 가격 계열만 가상 데이터로 바꾸는 데모 모드로 방향을 돌린 것이다. 서류는 아직 어디에도 내지 않은 상태라 외부에 노출된 링크는 없었다.

---

## 문제를 발견한 밤

예상 질문에 답을 적어 보던 밤이었다. 부분 실패 UI의 트레이드오프를 설명하다가 KIS 요청 한도 이야기가 나왔고, 거기서 웹소켓으로 바꾸면 어떤가를 찾아보게 됐다. 예전에 한 번 검토했던 소스라 가볍게 비용 자료를 읽고 있었는데, 한 줄에서 시선이 멈췄다.

> 증권사 API 시세는 계좌를 가진 개인이 도구 개발과 자기 투자 목적으로 쓰는 범위에서 제공된다

개인이 자기 투자 목적이라니. KIS와 KRX를 검토할 때 개인 개발 목적 사용이 가능하다는 건 분명히 확인했었고, 그건 똑똑히 기억한다. 내가 놓친 건 제공 대상이 "개인"에 국한된다는 사실이었다. 다시 말해, 지금까지처럼 서비스를 배포해 가격을 보여 주는 제3자 제공을 해서는 안 됐다. 짧은 순간 여기까지 생각이 닿은 뒤 처음 한 행동은 Vercel 대시보드를 열어 서비스를 내리는 것이었다.

KIS Developers FAQ(10월 초 게시)도 같은 말을 하고 있었다. 시세 데이터는 개인 고객 본인의 자산운용을 위한 투자 목적에 한해 활용할 수 있고, 근거는 고객 약관 제5조 ③ "시세정보를 개인의 업무에 한하여 이용해야 하며, 제3자에게 제공해서는 아니 된다"이다.

```
허용      본인 PC에 저장 · 가공 · 분석
허용 안 됨  불특정 다수가 이용 가능한 웹 및 앱 서비스 배포, 콘텐츠 업로드
기준      상업성이 아니라, 자기 자산에 쓰는지 남에게 보여 주는지
```

반년의 결과가 공중분해됐다는 생각에 좌절감이 밀려들었다. 하지만 정말로 이대로 버릴 수는 없는 노릇이라, 다음 날부터 되살릴 방법을 찾기 시작했다.

## 약관 전수 조사

처음 세운 가설은 "KIS만의 문제"였다. KIS를 다른 증권사 API나 공공데이터로 바꾸면 되지 않을까 싶어서, 코드가 닿는 소스 여섯 곳의 약관을 하루에 전부 읽었다.

| 소스 | 판정 | 근거 |
|---|---|---|
| KIS OpenAPI | 불가 | 제3자 서비스 제공은 법인 제휴 대상, 제도권 금융회사 아니면 제휴 불가. 시세는 제휴사도 KRX · 해외거래소와 별도 정보이용계약 필요 |
| KRX OPEN API | 불가 | 제11조② "제공받은 정보를 제3자에게 제공할 수 없다", ③ 계약 종료 후 보유 데이터 이용 불가 |
| 공공데이터포털 KRX상장종목정보 | 불가 | 공공누리 제4유형 + "상업적 목적 여부와 상관 없이 제3자 무단 제공 · 재배포 엄격히 금지" |
| 공공데이터포털 주식시세정보 | 불가 | 위와 같은 문구. 대체 소스로 못 씀 |
| pykrx(data.krx.co.kr) | 불가 | 홈페이지 약관 제10조② 자동화 수집 금지, 제12조② 복제 · 배포 금지. 수집부터 위반 소지 |
| OpenDART | **허용** | 이용 범위 · 제3자 제공 · 상업 이용 제한 조항 없음. 공공데이터포털에 등록된 금감원 재무 API 3건도 "이용허락범위 제한 없음" |

표를 채우면서 가설이 무너졌다. 국내 시세의 배포권은 KRX에 있고 유통은 코스콤이 맡는데, 코스콤 정보이용정책에는 비영리 · 개인 · 교육 면제가 없다. 증권사 API는 그 아래 층이라 어느 증권사로 바꿔도 같은 벽이 선다. 공공데이터포털의 KRX 데이터도 제공기관이 금융위원회일 뿐 재배포 금지 문구는 같았다. 거래소와 계약하지 않고 공개 웹에 국내 시세를 띄우는 무료 경로는 없다는 결론이었다.

한 가지 더 확인한 게 있다. KIS 호출만 끄고 DB에 쌓인 데이터로 화면을 그리면 되지 않나 싶었는데, 적재분도 출처가 같은 시세라 제3자 제공인 건 똑같았다. 개인 보유 · 개인 분석은 허용이지만 화면에 올리는 순간 범위를 벗어난다.

## 지금껏 몰랐던 이유

약관을 안 읽은 건 아니다. 읽었고, "개인 개발 목적 사용 가능"을 확인했다. 틀린 건 그 문장을 읽은 방식이었다. "개인 개발"을 쓰는 목적의 허용 범위로 읽었는데, 실제로는 제공 대상이 개인 한 사람으로 끝난다는 제한이었다. 개인이 개발해서 개인이 쓰는 것까지가 허용이고, 개인이 개발해서 남에게 보여 주는 건 그 밖이다. 기억보다 기록이 정확해서 예전 글들을 다시 열어 그때마다 무엇을 어떻게 읽었는지 적어 둔다.

| 시점 | 확인한 것 | 읽은 방식 |
|---|---|---|
| #002 데이터 소스 선정 | 비용(유료 API 월 \$70~99), 데이터 형태, 실시간성, KRX 승인 절차, 개인 사용 가능 여부 | "개인이 쓸 수 있는가"로 걸렀고, "개인 밖으로 내보낼 수 있는가"는 질문에 없었음 |
| #060 KIS 도입 | probe로 토큰 · 현재가 · 멀티 · 지수 4종 실측, 1분 1회 발급 제한, 30종목 한도 | 응답과 한도는 찍어봤지만 이용 범위는 "개인 개발 가능"으로 사용 가능한지만 판단 |
| #121 출처 · 라이선스 페이지 | lightweight-charts attribution 요건, DART · 공공데이터 출처 표기 | 라이선스를 "출처를 적는 일"로 다뤘고, 시세 데이터의 제공 범위는 점검 항목이 아니었음 |

아주 조금은 억울할 점이 있다면, 오해하기 쉬운 구조가 아닌가 하는 생각은 있다. 개인 키는 신청하면 승인됐고 용도를 묻고 판정하는 절차가 없었다. 제3자 제공 제한은 법인 제휴 안내 페이지에 있었고, 개인 개발자가 포털에서 키를 받아 예제를 돌리는 경로에서는 마주칠 일이 없는 자리였다. FAQ로 명시된 것도 10월 초였다. 그렇다고 약관 제5조 ③이 없었던 건 아니니 변명은 못 된다. "명세만 보고 짜는 대신 실제로 찍어본다"가 #060의 교훈이었는데, 찍어본 건 응답이었지 조건이 아니었던 셈이다.

## 회생방안

서비스를 어떻게 할지 네 가지를 놓고 봤다.

| 안 | 판정 |
|---|---|
| 배포 보호(비밀번호)로 공개 범위 축소 | 기각. 서류의 Live 링크가 바로 열리지 않고, 보호 안쪽이라도 불특정 다수 조건을 피했다고 보기 어려움 |
| KIS에 포트폴리오 데모 목적 제한 공개 허용 문의 | 기각. 답을 기다리는 동안 상태가 그대로이고, FAQ 문구상 예외 여지가 없음 |
| 시세를 D+1 공공데이터로 교체 | 기각. 같은 재배포 금지 문구. 장중 갱신이라는 서비스 성격도 사라짐 |
| **가격 계열을 가상 데이터로 바꾼 데모 모드** | **채택.** 약관 문제가 가격 계열에만 걸리고, 동작 · 구조 · 설계 결정은 데이터 출처와 무관하게 그대로 참 |

데모 모드 안에서 한 번 더 갈린 게 종목명이었다. 실제 종목명에 가상 가격을 붙이면 이질감이 있지 않을까 싶어 가상 기업 50~100개로 가는 안도 봤는데, 그러면 DART 실데이터인 재무 · 공시 · AI 요약까지 전부 가짜로 만들어야 한다. 앱에서 가장 설명력 있는 부분이 더미가 되는 셈이라 실명을 유지하고, 오인은 전 화면 배너와 첫 진입 안내, README로 막기로 했다. 종목명과 종목코드는 DART가 공개하는 정보라 출처 문제도 없다.

## 유지와 가상화의 경계

DART가 열린 덕에 가상화 범위가 가격 계열로 좁혀졌다. 기준은 하나였다. 데이터가 진짜여야 의미가 있는가, 숫자가 움직이기만 하면 되는가.

| 유지 (DART · 자체 데이터) | 가상화 (KIS · KRX · 공공데이터 유래) |
|---|---|
| 기업 목록 · 기업개황 | 현재가 · 시세 · 분봉 · 일봉 |
| 재무제표 5년 · 배당 | 국내 · 해외 지수 시세 · 분봉 · 일봉 |
| 공시 목록 · 원문 · AI 요약 | 순위(등락 · 거래량 · 시가총액 등) |
| 관심종목 · 메모 · 공시 요약 캐시 | 상장주식수 · 상장일 · 시장조치 · 휴장일 캘린더 |

가격 × 재무로 계산하는 지표(PER · PBR · 시가총액 · 시가배당률)는 가상이 된다. 숨기는 대신 배너와 툴팁으로 알리기로 했는데, 가상 가격의 수준을 DART 재무에서 잡으면 지표가 자연히 현실 범위에 들어온다는 계산이 있었다. 그 설계는 다음 글에서 다룬다.

## 하루 만에 V2까지

로드맵은 Phase 5로 새로 열었다. 조사(V0) → 모델 규칙(V1) → 생성기와 교체(V2) → 소스 교체(V3) → 배너 · 출처(V4) → 데이터 정리(V5) → 문서 · 재배포(V6), 기한은 1주이고 넘기면 Live 없이 지원을 시작하기로 했다.

V0에서 교체 지점이 lib/ 정규화 레이어 안에서 끝나는지부터 확인했다. 외부 호출은 전부 lib/를 거쳤고, 화면 쪽은 도메인 타입만 받고 있었다. route 세 개에 KIS 채널 구분과 지수 코드가 박혀 있었지만, 생성기가 그 시그니처를 그대로 받으면 route를 안 건드려도 됐다.

```
전: route → fetchStockQuote(ticker, "J" | "NX" | "UN") → KIS HTTP 호출 → 정규화 → 응답
후: route → fetchStockQuote(ticker, "J" | "NX" | "UN") → 생성기 함수 → 응답
     (route 수정은 import 경로뿐)
```

그래서 V2는 하루에 끝났다. 생성기 모듈 넷을 `lib/demo/`에 두고, KIS를 직접 부르던 어댑터 세 파일을 같은 export로 다시 썼다. KIS 토큰 · 정규화 코드 · 환경변수 · 테스트 107개를 지웠고, 헤더 현재가 = 분봉 마지막 봉 = 검색 목록 = 순위 안 가격 = 마감 스냅샷 = 일봉 종가가 서로 같은지를 정합 테스트로 묶었다. 실구현은 태그 `v1.0-portfolio`가 그대로 보존한다. 저녁 애프터마켓에 여섯 화면을 돌려 콘솔 에러 0을 봤다.

## 정리

- **V0 종결** — 소스 6곳 약관 판정(국내 시세 전부 불가 · DART 허용), 적재분도 제3자 제공, lib/ 경계 확인
- **V1 · V2 종결** — 데모 모드 결정, 유지/가상화 범위 분리, 생성기 `lib/demo/` 4모듈 + 어댑터 3파일 교체, KIS 코드 삭제, 정합 테스트 9, 테스트 1,144
- **Phase 5 신설** — 기한 1주, V3~V6 잔여. 세션 번호와 블로그는 #188부터 이어감
- **실명 종목 유지** — 가상 기업명 안 기각, 오인은 배너 · 첫 진입 안내 · README로

소스를 고를 때 "개인 개발 가능"에서 읽기를 멈춘 대가를 반년 뒤에 치른 세션이었다. 다만 치른 방식은 나쁘지 않았다고 본다. 확인한 날 밤에 내리고, 다음 날 여섯 곳을 전부 읽고, 무엇이 살고 무엇이 가상이 되는지 선을 그은 뒤에 코드를 열었다. 코드와 설계 결정은 데이터 출처와 무관하게 참이라는 것도 확인했고. 공중분해라고 느꼈던 건 하루 만에 "가격 계열만"으로 줄어들었다. 좀 늦었지만 서류를 내기 전에 알게 된 게 다행이라는 생각을 하고 있다.
