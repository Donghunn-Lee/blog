#125에서 등록한 F68 차례다. 분봉 차트의 시각 라벨이 HTS보다 1분(지수는 10분) 밀려 있는 문제 — HTS에서 09:01봉인 개장 봉이 우리 차트엔 09:00봉으로 찍힌다. KIS 분봉 응답의 시각이 봉 시작 라벨인데 HTS 관행은 마감 라벨이라, 규약이 반대인 걸 E50 검증 중에 발견하고 단독 세션으로 빼 뒀었다.

새 지수 1분 파이프라인(E61)이 틀린 라벨 규약 위에 올라가면 안 되니 의존상 제일 앞이고, 밤 시간대 세션이라 프리장 창 대안은 자동으로 빠졌다. 규약 실측부터 들어갔다.

## 규약 실측 — 판정 근거는 동시호가

#125에서 코드 경로는 전수해 뒀지만, "KIS 분봉 시각 = 봉 시작 라벨"이라는 판정 자체는 코드 주석과 관측에 기대고 있었다. 공식 문서에 명시가 없어서 실호출로 확정했다.

결정적 근거는 마감 동시호가 구간이었다.

```
151900  v=31,252     ← 연속매매 마지막 분
152000~152900  v=0   ← 동시호가, 가격 프리즈
153000  v=1,058,643  ← 마감 크로스
```

END 라벨이라면 152000봉이 15:19~20 체결을 담아야 하는데 볼륨이 0이다. START 해석([15:20, 15:21))에서만 설명이 된다. 개장 쪽도 같았다 — 090000봉에 시가 크로스 대용량, 090100봉이 첫 연속매매. 지수 1분·10분도 동일 패턴이라 국내는 전부 **START 확정**.

해외는 다른 답이 나왔다.

| 지수 | 호출 21:04 KST 시점 최신 봉 | 해석 |
|---|---|---|
| DAX | 13:48 (프랑크푸르트 장중) | CEST — 거래소 현지 |
| COMP | 전일 16:15 | ET — 거래소 현지 |

지수마다 거래소 로컬 시각이라 단일 타임존 가정이 불가능하다는 것까지. 이건 E61 적재 설계의 입력으로 넘어간다.

## 시프트 위치 — 세 후보 중 리샘플 뒤

+1분 이동을 어디서 하느냐가 이번 설계의 본체였다.

| 후보 | 기각/채택 사유 |
|---|---|
| 정규화 단계 (시각→epoch 헬퍼) | 기각 — floor 리샘플 경계 붕괴 + 테스트 하드코드 전면 갱신 |
| 표시층 포맷터 | 기각 — 라벨만 바꿀 수 있고 봉 병합이 구조적으로 불가 |
| **최종 조립 직전 변환 유틸** | 채택 — 내부는 KIS 원생 START 유지, 기존 유틸·테스트 전부 무변경 |

두 번째 기각 사유가 곧 이번 작업의 핵심 발견이다. 시프트만으론 안 된다 — 지수 10분에서 152000(프리즈)과 153000(크로스)을 각각 +10분 하면 15:30, 15:40 두 봉이 되는데 HTS는 이걸 15:30 한 봉으로 그린다. "경계를 넘으면 경계로 클램프하고, 같은 라벨끼리 병합"이 규칙에 들어가야 했다.

```
1. time' = time + interval
2. 경계 초과 시 클램프 (raw ≤ 경계 && time' > 경계)
3. 라벨 충돌 병합: open=선행 · close=후행 · 고저 극값 · vol 합
```

이 규칙에 실측값을 대입하면 15:30 병합 봉이 시가=동시호가 프리즈값, 종가=마감 크로스로 나온다. HTS 봉과 의미까지 일치.

종목/지수의 플랫 표시 차이는 공짜로 해결됐다. HTS 기준 종목 1분은 15:20 다음이 바로 15:30(플랫 없음)이고 지수는 15:21~29 플랫이 쌓이다 15:30 캔들인데, 종목엔 #112에서 넣은 갭 컷이 v=0 창을 이미 지우고 있다. 유틸에 분기 없이 상류 컷 유무만으로 양쪽이 맞았다.

해외는 스코프에서 뺐다. HTS 화면이 답을 줬는데 — 첫 봉 09:30, 마지막 16:15. HTS 자체가 해외는 raw START를 그대로 표시하고 있었다. 우리 차트도 raw 표시라 이미 정합이고, 여길 고치면 오히려 어긋난다. 국내/해외 규약이 갈리는 게 좀 찜찜하긴 한데, 그 갈림이 HTS 관행 자체라 미러링으로 수용했다.

## 개장 검증에서 나온 5/15분 결함

구현·게이트까지 밤에 끝내고, 다음 날 아침 HTS 대조에서 걸렸다. 1분봉은 맞는데 5분봉 첫 봉이 08:00이다(정답 08:05). 15분도 같고, 08:49 시점 최신 봉이 08:45다.

(스크린샷: 5분봉 첫 봉 08:00 결함)

원인은 바로 나왔다. "변환은 마지막 리샘플 이후"라는 원칙을 세워놓고, 정작 변환을 서버 서빙 단계에 넣었다. 종목 5/15분은 그 뒤 클라에서 리샘플되고 있었고, END 라벨에 floor 버킷이 걸리니 설계 때 우려한 붕괴가 정확히 그 모양으로 났다. 원칙이 틀린 게 아니라 적용 위치가 원칙을 어긴 거다.

수정은 종목 변환을 클라 조립으로 옮기는 것.

```
전: 서버 END 변환 → 클라 merge → 리샘플 → 표시
후: 서버 raw START → 클라 리샘플 → END 변환 → merge → 표시
```

부수 이득도 있었다. 확장 세션 봉 검출이 시프트 전 raw 기준이 되면서, 경계봉이 시프트로 검출 창을 빠져나가는 이론 케이스가 구조적으로 사라졌다.

## 애프터 마감봉 20:01 — 경계 목록화

수정 후에도 하나 남았다. NXT 종목의 전일 애프터 마감봉이 20:01로 찍혔다. 클램프 경계를 15:30 하나만 넘겼으니 20:00 크로스가 균일 시프트로 빠져나간 거다.

경계를 단수에서 목록으로 일반화했다 — "raw 시각 이상인 최소 경계를 넘으면 그 경계로". 종목은 [08:50, 15:30, 20:00], 지수는 [15:30]. 병합 규칙은 그대로라 프리·애프터 마감 크로스가 같은 코드로 처리된다.

검증은 vitest 599 pass(신규 19케이스 — 리샘플→변환 통합 케이스 포함)에 개장 육안까지: 1/5/15분 첫 봉, 지수 10분 09:10, 애프터 마감봉 20:00 전부 HTS 일치. 오후 마감 봉과 시간외 구간 라벨(#116에서 본 에코 의심 구간과 겹친다)은 세션 밖 체크로 남겼다. 어긋나면 경계 상수 한 줄 후속이면 된다.

## E32는 조치 불요, 대신 E62

F68이 생각보다 일찍 접혀서 E32(관심종목 폐장 가격 미표시)를 붙였다. 사실 뭐가 문제인지 나도 정확히 몰라서 구조 조사부터 돌렸는데 — 재현이 안 됐다. 관심종목 경로는 이미 EOD + 마감 스냅샷 + 라이브 세션 분기의 3층 fallback이고, 병합도 검색 표와 동형이었다. 로드맵에 적어둔 "이식 필요"가 낡은 전제였던 거다. 폐장 시간대에 직접 열어봐도 멀쩡해서 조치 불요로 닫았다. 조사 후 조치 불요도 처리로 치는 #125 정책의 수혜다.

대신 조사 화면에서 다른 게 보였다. 폐장 후 관심종목 가격이 KRX 종가와 다른데(NXT 20시 최종가가 반영된 UN 종가다) 출처 표시가 없다. 확인해 보니 순위 슬레이트는 KRX 고정 — 화면마다 기준이 다른데 사용자에게 알려주는 게 없다.

배지로 풀기로 했다. 다만 상시 배지는 소음이라, **KRX 종가와 다른 가격일 때만** 붙는 조건부로. 판별 기반으로 quote 모델에 source 필드 하나를 태깅하는 설계까지 잡고 E62로 등록했다. 구현은 다음 차례에.

## 아침 창 부수 소화

세션이 익일 아침까지 걸친 김에, 개장 전후에만 되는 것들을 같이 치웠다.

- **E50 프리장 육안** — NXT 탭 프리 시세·등락 기준(KRX 전일 종가) 정합. KRX 탭은 KIS가 09시 전까지 전일 세션 값을 주는 걸 기준일 라벨과 함께 그대로 표시하는 거라 조치 불요. 이걸로 E50 완전 종결
- **X18 선행** — UN pre 시간대 quote 전 필드 raw 캡처. 분석은 착수 세션으로 넘기지만, X18이 아침 창 제약에서 풀렸다
- **E61 개장 경계** — 지수 1분 첫 봉 090000 확정. 응답에 마커 행이 섞여 오고 전일 봉과 혼재라 행별 날짜 파싱이 필요하다는 것까지, 적재 설계 입력이 채워졌다

## 정리

- **F68 종결** — 국내 분봉 START→END 라벨 전환. 변환 유틸(클램프+병합) 신설, 적용 위치는 "마지막 리샘플 이후·merge 이전"으로 확정. 해외는 HTS 관행 미러링으로 제외
- **E50 완전 종결** — 프리장 육안 green, #124부터 끌고 온 잔여 소멸
- **E32 조치 불요 종결** — 3층 fallback 기존재, 전제 무효
- **E62 신설** — 조건부 가격 출처 배지 + source 필드 설계 확정
- **E61·X18 선행 소화** — 개장 경계 실측·pre 캡처로 다음 세션들 부담 축소

#125가 찾은 결함을 실측→설계→구현→검증으로 닫은 세션인데, 원칙을 세우고도 적용 위치에서 한 번, 경계 개수에서 한 번 틀렸다. 둘 다 게이트가 아니라 HTS 대조 육안이 잡았다. 규약류 수정의 검증은 테스트가 아니라 실물 대조라는 걸 다시 확인한 셈이다.

## 다음 작업

F68이 닫히면서 E61 진입 조건이 갖춰졌다. 잔여 probe도 아시아 3종 타임존과 서머타임 전환일 정도만 남았다.

- **E61** — 지수 intraday 통일 아크. 국내 4종 1분봉 적재부터 해외 4종 승격, 세션 축 분기까지
- **X18** — NXT 구조 통일. 선행 캡처가 끝나 아침 창과 무관하게 편성 가능해졌다

E61이 세션 몇 개짜리 아크라, 사이사이 sweep 소형 항목을 tail로 붙이는 이번 방식을 유지할 생각이다.
